# Viloyatlar bellashuvi — 3D xarita

Har bir obunachiga — bitta uy. O‘zbekiston 3D xaritasida uyingizni, qo‘shnilaringizni va viloyatlar bellashuvini ko‘ring.

- Statik sayt: `index.html`, `style.css`, `app.js` (Three.js), ma’lumot `data/houses.json`.
- Xarita chegaralari: geoBoundaries UZB ADM1 (CC BY 4.0).
- Lokal ko‘rish: `node serve.mjs` → http://localhost:5180
